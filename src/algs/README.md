# algs Module

## Overview

This module contains the **implementation of PaKS** and the corresponding algorithm **configuration** used in the computational experiments.

The folder contains two modules:

- `configs.py` - contains algorithm configurations as dictionaries; the default configuration represents the parameter settings used in the computational experiments reported in the manuscript (Table 3)

- `paks.py` - implements the PaKS algorithm, including its initialization, kernel construction, bucket generation, and improvement phase
