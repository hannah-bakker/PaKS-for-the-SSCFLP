# Results

## Overview

In this folder, **results generated by running the algorithms** implemented in `scripts/main.py` are stored.

One example output file is provided to illustrate the structure of the results generated by PaKS:  
`3600s-default-i300_1.json`.

This file contains the results of running PaKS on instance `i300_1` with a time limit of 3600 seconds.

In addition, the summary file `PaKS_CompleteResults.xlsx` consolidates the main results reported in the manuscript.
